Getting started

  1. Add a question manually, or import a JSON/CSV file.
  2. Choose a topic and examination year for each question.
  3. Open Practice to answer questions and check explanations.
  4. Export a JSON backup regularly so you don't lose your collection.
Acode preview may not preserve browser storage when reopened. After every change, prepare a fresh backup and update your JSON file in QuickEdit before closing.

Import questions from a file

Select a JSON or CSV file. Imported questions are added to your existing bank.

File format

JSON question fields: part, topic, year, question, options (at least two choices), answer (letter or zero-based index), explanation. Variable option counts are supported. CSV headers: part, topic, year, question, A, B, C, D, answer, explanation.

Duplicate manager

Scan your question bank for repeated questions. A duplicate means the same examination year, question wording, and answer choices, even if its topic, difficulty, or option order differs.
